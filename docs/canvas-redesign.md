# 无限画布交互与数据契约

画布采用 **素材 → 生成卡 → 结果组**。选择负责查看和整理，生成卡保存下一次创作的草稿，运行记录保存实际提交的输入。所有生成继续复用 `App.jsx` 的认证、轮询、额度和经典历史链路。

## 用户操作

| 操作 | 行为 |
| --- | --- |
| 新建生成 | 创建独立生成卡，在固定右侧面板编辑提示词、参考顺序、模型、比例、质量与数量。 |
| 选择素材 | 仅查看详情，不加入输入，不恢复历史提示词；保留返回当前草稿的入口。 |
| 基于此图修改 | 创建仅引用该图片的新草稿，正文为空，不继承上游或旧提示词。 |
| 添加到当前草稿 | 明确将素材加入该生成卡的统一参考清单。 |
| 复用生成参数 | 根据运行时的实际正文、图片快照与参数创建新草稿。 |
| 标注修改 | 另存标注素材并创建草稿，原图与旧任务保持不变。 |
| 多选 | 整理、复制、对齐、移除；“用所选图片创建生成”只采用已完成的选中图片。 |
| 生成一组 | 在生成卡右侧新增结果组并避让已有内容；保留草稿、选择与视口。 |

文本默认是便签，双击进入编辑，支持八方向调整文本框；图片使用标准显示尺寸且不可拉伸。保留滚轮平移、Ctrl/⌘ 滚轮锚点缩放、空格/中键/右键平移、框选、鼠标位置粘贴、原位偏移克隆与撤销重做。

## 唯一输入清单

生成卡的有序 `refs` 是唯一输入清单。连线、上传、画布选择、历史和 `@` 都调用相同添加逻辑；图片按内容哈希或历史图片 ID 去重。不从选择、坐标或旧父子关系隐式推导输入。

- 画布选参考锁定目标草稿；点击只暂存候选，完成后统一加入，取消或 Esc 不改原引用。
- 直接上传保留为项目素材，不创建可见节点。素材抽屉提供重新显示和再次引用入口。
- `@` 提供可读素材搜索，选择后加入参考列表并去掉临时搜索串，不向新输入框写入节点 ID 令牌。
- 文本按列表顺序拼接，然后追加本次正文；图片也保持彼此在列表中的顺序。
- 预览和提交共用 `resolveGenerationInput`。缺失素材、未完成图片、空文本和超过 8 张图片均阻止提交，不能静默少传。
- 至少需要有效正文或有内容的文本引用。图片本身不能替代提示词。

## 连线与结果

素材右端连接生成卡左端表示可编辑参考；移除连线等同移除该草稿的引用项。素材右端拖到空白创建生成卡；生成卡左端拖到空白添加文本或上传输入。保留磁性吸附、节点连接端与松手点对齐，以及菜单期间冻结待定线。图片之间不再提供含义不明的普通连线。

运行时来源线只读。查看结果时展示原运行的输入，编辑草稿时展示草稿输入。结果按运行分组，组头可整体拖动，图片仍可单独移动、预览、下载和再次引用。明确点击适应内容、聚焦或定位结果才调整视口。

## 运行与恢复

提交前冻结输入与参数，异步读取图片期间的编辑也不会改写本轮请求。按钮有同步提交锁，避免双击创建重复批次。

| 操作 | 请求与新增消耗 |
| --- | --- |
| 恢复任务 | 沿用原请求 ID，不重复调用上游或扣费。 |
| 重试失败项 | 使用原运行快照，仅为确定失败项创建新请求，显示预计新增额度。 |
| 再生成一组 | 使用原运行快照与数量创建新批次，显示整组预计消耗。 |

重试不覆盖原批次成功图片。服务器负责额度和退款。移除运行中的节点不代表取消请求或退款，运行记录仍可恢复显示结果。撤销布局与草稿不会撤销已经发生的生成、运行记录或扣费。

## 数据与迁移

- `nodes` 保存几何布局、可见性、素材和草稿引用；生成图片只引用原 `taskId/imageId`，不复制经典历史 Blob。
- `drafts` 保存可编辑草稿；`runs` 保存不可变输入快照和任务 ID。
- 任务 `canvasContext` 包含 `canvasId/runId/draftId/draftNodeId/inputPrompt/inputSnapshot/anchor`。`task.prompt` 与 `task.referenceImages` 保存真实请求正文与图片版本。
- 布局、草稿、运行、素材、视口及 fallback 都按 `canvasId` 隔离。补齐结果按照任务内图片索引落位，手动导入别的项目的历史图片仍保留。
- 从画布移除只隐藏节点，仍被引用的素材及 Blob 保留。当前不提供彻底删除素材。项目保存在当前浏览器，不承诺云同步或分享。
- IndexedDB schema 3 在转换前将旧完整快照保存在 `backups` store，每项目保留一次；`loadCanvasMigrationBackup` 可读取备份用于恢复排查。
- 旧空图像转为生成卡；明确引用与直接上传转为统一参考；旧全局提示词只转为一个“未归属草稿”，旧 `@` 令牌仅在迁移时解析。
- 无法证明是实际输入的旧 `parentIds` 保留为 `legacyParentIds`，不自动加入新任务；实际历史参数优先来自原任务记录。
- 缺失 Blob 保留占位与错误提示，加载失败不能保存空数据覆盖原项目，迁移本身不执行生图。

## 验证

`pnpm test` 验证输入解析、快照冻结、缺失引用、迁移幂等及原有 API/额度/恢复规则。

`pnpm run test:browser` 使用隔离开发 API、模拟图片供应商和真实浏览器，覆盖独立草稿、真实引用/标注请求、落位、部分失败和恢复、画布手势、项目管理、迁移备份、历史保留及经典模式。测试不使用生产邮件或付费生图接口。
